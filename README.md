# Отмотка (Rewind)

Fabric-мод для Minecraft 1.21.1. У игрока появляется личное время: он умеет
вернуть в прошлое **себя**, не возвращая туда мир.

> Ты не отменяешь произошедшее. Ты переживаешь его ещё раз — и получаешь шанс
> поступить иначе.

Зомби, который тебя ударил, остаётся стоять там же. Стрела не возвращается
в колчан. Выброшенный алмаз лежит там, где упал. Назад возвращаешься только ты.

## Что уже работает

Реализованы фазы 1–3 технического задания: серверное ядро способности.

- кольцевой буфер снимков игрока (по умолчанию 10 секунд, 20 снимков в секунду);
- классификация входящего урона по типам угроз;
- автоматическая отмотка на уровнях 1–4;
- временная энергия, долг, кулдауны, адресная защита после отмотки;
- прогрессия: мастерство с убывающей отдачей и открытие уровней;
- сохранение состояния между входами и перезапусками сервера;
- отладочные команды `/rewind`.

Ручная отмотка по клавише, HUD, визуальные эффекты, свои звуки и структура
Temporal Rift относятся к фазам 4–8 и пока не сделаны. План: [`docs/superpowers/plans/2026-09-14-rewind-phases-1-3.md`](docs/superpowers/plans/2026-09-14-rewind-phases-1-3.md).

## Как получить способность

По замыслу способность даёт редкая аномалия — Temporal Rift с реликвией внутри
(фаза 7). Пока её нет, способность выдаёт оператор:

```
/rewind unlock <игрок>
```

Для тестов можно включить `grantOnFirstJoin` в конфиге — тогда способность
получает каждый, кто впервые зашёл на сервер.

## Уровни

Способность растёт от инстинкта к контролю. Каждый следующий уровень требует
и накопленного мастерства, и **встречи** с новой угрозой: защиту от взрывов
нельзя получить, ни разу не услышав шипение крипера. Умирать при этом не
обязательно — достаточно столкнуться.

| Уровень | От чего спасает автоматически |
|---|---|
| 1 | ближний бой: зомби, пауки, пиглины, удар мечом |
| 2 | + снаряды: стрелы, трезубцы, фаерболы |
| 3 | + взрывы: криперы, динамит, кровать в Нижнем мире |
| 4 | + окружение: огонь, лава, падение, удушье, яд, магия, иссушение, обморожение, кактус |
| 5 | осознанное управление временем (фаза 4) |

## Автоматическая отмотка

На уровнях 1–4 способность работает сама и только тогда, когда дело плохо:
по умолчанию она срабатывает, если удар оставит меньше 20% здоровья или убьёт.
Порог настраивается — можно потребовать, чтобы отмотка включалась только
на смертельном уроне.

Отмотка возвращает игрока на 0.6 секунды назад, стоит 20 единиц временной
энергии и уходит на пятисекундный откат. Сразу после неё даётся короткая
защита от **той же** угрозы — иначе лава ударила бы снова следующим тиком
и цикл никогда бы не кончился. От всего остального мира защита не спасает:
проблема никуда не делась, её всё ещё надо решать.

## Энергия и долг

Временная энергия (по умолчанию 100) восстанавливается сама, одна единица
в секунду. Ручная отмотка вдобавок создаёт **временной долг**: пока он не
рассосался, энергия восстанавливается вчетверо медленнее. Это и есть
предохранитель от цепочки «отмотался — восстановился — отмотался».

## Что не откатывается никогда

Это не система сохранений. Мир не возвращается назад ни при каких условиях:

- блоки, контейнеры и их содержимое;
- мобы, их здоровье, цели и состояние;
- снаряды, динамит, редстоун;
- время суток, погода, генерация мира;
- действия других игроков;
- **предметы в инвентаре** — съеденный стейк не вернётся, потраченная стрела
  тоже, а полученный алмаз не исчезнет;
- **опыт** — ни полученный, ни потраченный;
- прочность инструментов, продвижения, статистика.

Снимок игрока хранит только позицию, скорость, поворот, здоровье, сытость,
воздух, горение, обморожение и активные эффекты. Ничего экономического в нём
нет — поэтому дюп предметов не «запрещён проверкой», а физически невозможен.

## Мультиплеер

У каждого игрока своё время. Если отматывается A, то B не теряет ничего:
ни выпущенной стрелы, ни потраченного зелья, ни нанесённого удара. B просто
видит, как A возвращается туда, где был пару мгновений назад.

## Команды

Требуют прав оператора; `force` и `debug` — третьего уровня.

```
/rewind unlock <игрок>            выдать способность
/rewind level <игрок> <0..5>      выставить уровень
/rewind energy <игрок> <сколько>  выставить энергию
/rewind mastery <игрок> <сколько> выставить мастерство
/rewind force <игрок> <секунды>   принудительная отмотка
/rewind clear <игрок>             очистить буфер, защиты и кулдауны
/rewind debug <игрок>             показать всё состояние
```

## Сборка

Нужен JDK 21 или новее (Gradle сам подтянет нужный toolchain).

```
./gradlew build      # джарник в build/libs/
./gradlew test       # юнит-тесты
./gradlew runServer  # тестовый сервер в run/
```
