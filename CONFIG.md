# Настройки

Файл `config/rewind.json` создаётся при первом запуске со значениями по
умолчанию. Все балансные числа мода живут только здесь — в коде их нет.
Конфиг читается один раз при старте сервера, так что после правки нужен
перезапуск.

## Общее

| Поле | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | Выключает мод целиком: ни снимков, ни отмоток, ни команд по существу |
| `maxLevel` | `5` | Потолок прогрессии. Понизив до 4, вы отключаете осознанное управление временем |

## Буфер снимков

| Поле | По умолчанию | Что делает |
|---|---|---|
| `bufferSeconds` | `10.0` | Насколько глубоко в прошлое вообще можно дотянуться |
| `snapshotsPerSecond` | `20` | Частота снимков. 20 — каждый тик, максимум точности. Значение должно быть делителем 20, иначе округлится вниз |
| `dimensionChangeClearsBuffer` | `true` | Обнулять буфер при смене измерения. Выключать не стоит: иначе появляется отмотка из Нижнего мира в Верхний |
| `deathClearsBuffer` | `true` | Обнулять буфер при смерти |

Размер буфера в памяти — `bufferSeconds × snapshotsPerSecond` записей на
игрока (по умолчанию 200).

## Энергия

| Поле | По умолчанию | Что делает |
|---|---|---|
| `maxEnergy` | `100.0` | Потолок временной энергии |
| `energyRegenPerSecond` | `1.0` | Скорость восстановления без долга |
| `autoEnergyCost` | `20.0` | Цена автоматической отмотки. По умолчанию это пять спасений подряд с полного запаса |
| `manualBaseCost` | `40.0` | Базовая цена ручной отмотки (фаза 4) |
| `manualCostPerSecond` | `8.0` | Надбавка за каждую секунду глубины: `цена = база + секунды × надбавка` |

## Временной долг

| Поле | По умолчанию | Что делает |
|---|---|---|
| `debtRegenMultiplier` | `0.25` | Во сколько раз медленнее идёт восстановление, пока долг не погашен |
| `debtDecayPerSecond` | `0.5` | Скорость погашения долга |
| `maxDebtSeconds` | `30.0` | Потолок долга, чтобы он не превращался в вечное наказание |

## Отмотка

| Поле | По умолчанию | Что делает |
|---|---|---|
| `autoRewindSeconds` | `0.6` | Глубина автоматической отмотки. Достаточно, чтобы уйти из-под удара, и мало, чтобы отменить бой |
| `manualMaxSeconds` | `7.0` | Предел глубины ручной отмотки (фаза 4) |
| `autoCooldownSeconds` | `5.0` | Откат автоматической отмотки. Именно он не даёт пережить два смертельных удара подряд |
| `manualCooldownSeconds` | `8.0` | Откат ручной отмотки |
| `temporalProtectionSeconds` | `0.8` | Сколько длится адресная защита после отмотки |

## Порог опасности

| Поле | По умолчанию | Что делает |
|---|---|---|
| `dangerMode` | `"HEALTH_PERCENT"` | Режим: `HEALTH_PERCENT`, `DAMAGE_PERCENT` или `LETHAL_ONLY` |
| `dangerHealthPercent` | `0.20` | Для `HEALTH_PERCENT`: отмотка, если после удара останется меньше этой доли максимального здоровья |
| `dangerDamagePercent` | `0.35` | Для `DAMAGE_PERCENT`: отмотка, если один удар снимает больше этой доли максимального здоровья |

Смертельный урон считается опасным во всех режимах, включая `LETHAL_ONLY` —
иначе режим оказался бы строже самого себя.

Порог считается по урону **до** брони, поэтому способность иногда срабатывает
чуть раньше, чем строго необходимо. Это осознанное упрощение.

## Мастерство и уровни

| Поле | По умолчанию | Что делает |
|---|---|---|
| `masteryPerRewind` | `20.0` | Базовое мастерство за удавшуюся отмотку |
| `masteryFirstEncounterBonus` | `50.0` | Разовая надбавка за первую встречу с новым типом угрозы |
| `diminishing` | `[1, 1, 0.75, 0.5, 0.25, 0]` | Множители за первый, второй, третий… повтор одного источника. Последнее значение действует и дальше |
| `diminishingResetMinutes` | `10` | Через сколько минут множители восстанавливаются |
| `masteryPerLevel` | `[0, 120, 320, 700, 1400]` | Порог мастерства для уровней 1–5 |

Уровень требует и мастерства, и встречи с угрозой, которую он открывает:
второй — со снарядом, третий — со взрывом, четвёртый — с любой угрозой
окружения. Пятый встречи не требует.

## Прочее

| Поле | По умолчанию | Что делает |
|---|---|---|
| `fractureSeconds` | `20.0` | Длительность временного перелома — состояния, в котором способность молчит, а энергия не восстанавливается |
| `grantOnFirstJoin` | `false` | Выдавать способность каждому при первом входе. Только для тестов: по замыслу её даёт Temporal Rift |
| `serverFeedbackEnabled` | `true` | Сообщения над хотбаром, звук и частицы при отмотке |
| `soundEnabled` | `true` | Только звук |
| `nearRewindTickSeconds` | `1.0` | Как часто тикает предупреждение, когда здоровья мало, а страховка есть. `0` — не тикать |

## Примеры

**Хардкор: отмотка спасает только от смерти и редко.**

```json
{
  "dangerMode": "LETHAL_ONLY",
  "autoCooldownSeconds": 20.0,
  "autoEnergyCost": 50.0,
  "energyRegenPerSecond": 0.4
}
```

**Мягко: способность как страховка новичка.**

```json
{
  "dangerHealthPercent": 0.40,
  "autoCooldownSeconds": 2.0,
  "autoEnergyCost": 10.0,
  "grantOnFirstJoin": true
}
```

**Экономия памяти на большом сервере** (буфер вчетверо меньше, точность
снимков падает до пяти в секунду):

```json
{
  "bufferSeconds": 6.0,
  "snapshotsPerSecond": 5
}
```
