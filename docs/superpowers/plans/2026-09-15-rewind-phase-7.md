# Фаза 7 — обретение способности (ТЗ §38, §39)

## Решения владельца (2026-09-15)

- Разлом (**Temporal Rift**) — **под землёй, редко**, полость в толще камня.
- Найти его можно **на слух**: тихий гул и редкий щелчок в радиусе ~40 блоков.
- Первая отмотка идёт **без HUD**: карточка и подсказка появляются через
  несколько секунд, чтобы момент читался как «что-то произошло», а не как
  выдача способности.
- **Реликвия уносится с собой**, на её месте остаётся **погасший постамент** —
  метка того, что тут кто-то был.
- Реликвия носится **через Accessories** (Curios на Fabric не существует),
  зависимость **мягкая**: без мода реликвия остаётся обычным предметом.
- Надетая реликвия ускоряет **восстановление энергии (×1.25)**.
- **Компас к разлому** — стрелка, как у компаса на лодстоун.

## Как это устроено

1. **Постамент** `rewind:temporal_pedestal`, свойство `lit`. У зажжённого есть
   блок-сущность с серверным тикером: она и издаёт гул. Радиус слышимости берём
   громкостью (в Minecraft дальность = 16 × volume), своего кода на радиус нет.
2. **Разлом** — структура `rewind:temporal_rift` типа `jigsaw`, чей единственный
   элемент пула — `feature_pool_element`. Сама полость с постаментом рисуется
   своей `Feature` на Java. Через структуру бесплатно получаются `/locate`
   и поиск незагруженных чанков для компаса.
3. **Взаимодействие** с зажжённым постаментом: первая неконтролируемая отмотка
   (в обход энергии и уровня), `unlocked = true`, `level = 1`, в руки —
   реликвия, постамент гаснет навсегда.
4. **Temporal Fracture** (§39): поле `fractureTicks` в коде уже есть и уже
   блокирует отмотку с восстановлением энергии, но его никто не выставлял.
   Выставляем после смерти.
5. **Компас** на правый клик ищет ближайший разлом через `locateStructure`
   и пишет результат в компонент `lodestone_tracker` — дальше стрелку крутит
   ванильный механизм.

## Порядок работ

1. Блоки, блок-сущность, гул.
2. Feature разлома + JSON мира (структура, набор структур, пул, тег).
3. Взаимодействие, первая отмотка, выдача реликвии.
4. Перелом после смерти.
5. Реликвия и мягкая совместимость с Accessories.
6. Компас: предмет, модель с ванильными поворотами, клиентский предикат.
7. Тишина HUD на первые секунды.
8. Локализация, звуки, тесты, отладочная команда установки постамента.
